# Island reference v1

This specific image was created with the built-in image generation tool as a
modeling reference. It was not applied as a texture in the first model pass.
Generated images are now permitted for actual texture production as well;
see the pending work document in `Docs/PENDING_WORK.md` for the updated instruction.

Prompt: Create an original cozy life-simulation island inspired by the friendly
proportions of Animal Crossing, without franchise characters or logos. Elevated
three-quarter aerial view from the south, whole island visible. Compact irregular
oval island about 90 meters wide, creamy sandy shore, turquoise sea, grassy main
level, low rounded northern cliff plateau, curved tan footpath and round plaza,
three peach/cream/sage cottages with teal, terracotta and mustard roofs, south dock,
broadleaf and fruit trees, flowers, rounded rocks and wooden fences. Open walkable
layout, south-facing cottage doors. Rounded handcrafted toy-like 3D forms, warm
daylight, coral/cream/sage/mint palette. No text, UI, labels, watermark or people.

The image guides the palette, materials and proportions. The first model pass
uses a smaller set of details and moves the third cottage onto the upper plateau.
