# AstraLevelTest 작업 지시서

사용자 지시를 작업 중 계속 갱신한다. 작성일: 2026-09-07 (Asia/Seoul).

## 프로젝트와 제작 방식

- 현재 저장소 하위 `AstraLevelTest` 폴더에 Unreal Engine **5.7** 프로젝트를 만든다. 설치 버전은 5.7.4.
- 예상되는 게임 렌더 화면을 **이미지 생성으로 먼저 제작**하고 그 아트 방향을 기준으로 구현한다.
- 전체 배치 이미지는 작은 물체의 구조가 잘 보이지 않으므로 **개별 사물 모델링용 세부 참고 이미지를 별도로 생성**한다.
- **생성한 참고 이미지를 모두 프로젝트 안에 저장**한다. 사용한 텍스처와 생성 프롬프트 기록도 보관한다.
- 숲에 필요한 모델은 **Blender 스크립트로 생성**한다.
- **블렌더에서 전체 배치를 작성하고, 모델별 위치·회전·크기를 JSON으로 추출해 언리얼에 적용**한다.
- 블렌더 지형 높이 데이터도 함께 추출하고, 언리얼 지형은 실제 **Landscape**로 구성한다.
- 텍스처가 필요한 곳에는 이미지 생성을 이용한다.
- 탑다운 게임이므로 근접 시점용 세부 묘사는 필요 없다. 큰 형태·실루엣·색감과 화면 가독성을 우선한다.
- 새 TRS 기즈모 플러그인은 필요하지 않다. 회전·배치는 수치와 추출된 변환 데이터로 적용할 수 있다.

## 공간과 환경

- 크기는 **약 100 × 100m**. 기술적 Landscape 크기는 100.8 × 100.8m (127×127 높이 샘플, 간격 80cm).
- 숲, 공터, 호수, 개울물, 나무다리, 무너진 나무다리, 부서진 목조 건물을 포함한다.
- 호수와 개울 주변에는 **연꽃과 수초**를 배치한다.
- 바위는 회전·기울기·크기를 다양하게 하고 지면에 자연스럽게 묻어 배치한다.
- 중앙 공터와 주요 장소를 걸어서 탐색할 수 있도록 동선과 충돌을 구성한다.
- 작은 물웅덩이에는 **애니메이션 배경풍 하늘이 비친다**.
- 추가 수정 지시: 호수·개울·물웅덩이의 명확한 수면 경계를 마스크로 부드럽게 처리한다.
- 물웅덩이에 하늘 이미지를 직접 매핑하던 방식은 폐기한다. 실제 스카이에 구름을 넣고 반사 재질이 하늘과 주변 환경을 반사하도록 한다.
- 호수와 웅덩이가 칙칙하고 탁해 보이지 않도록 맑고 산뜻한 색과 반사를 구현한다. 흐린 반복 무늬와 과도한 흰 반사광을 줄이고 실제 엔진 렌더로 확인한다.
- 핑크 집 레퍼런스의 호숫가 수면을 목표로 삼아 구현 가능성과 방법을 새 작업에서 추론 강도 ultra로 검토한다. 품질을 위해 시간이 오래 걸려도 괜찮다.
- 최신 수면 작업에서 전달된 수정 지시: **호수·개울에는 하늘/구름 반사를 넣지 않는다.** 작은 물웅덩이는 **착시·텍스처 트릭 사용을 허용**한다. 이 지시는 위의 실제 반사 방식 지정에 우선한다.
- 호수의 화면상 오른쪽(3시 방향) 호숫가에 분홍색 지붕의 귀여운 집을 계획한다. 현관문은 게임 화면을 바라보고 앞에는 우물을 둔다. 우선 별도의 모델링 레퍼런스 이미지를 병렬 제작한다.

## 캐릭터, 조작과 카메라

- 마인크래프트처럼 **박스 형태의 직립 보행 삼색털 고양이**.
- 흰색·주황색·검은색의 비대칭 삼색 무늬. 두 발로 걷고 팔·다리·꼬리가 보인다.
- **WASD** 이동. **마우스 조작 없음**.
- **카메라 회전 없음**. 고정된 탑다운 각도를 유지하며 2D 게임처럼 캐릭터를 따라 이동한다.

## 조명

- 귀여운 게임에 맞춰 날카로운 기본 그림자를 피한다.
- Directional Light의 **Source Angle = 50°**를 적용한다.
- 실제 언리얼 렌더에서 그림자의 부드러움과 전체 색감을 검증한다.
- Exponential Height Fog를 추가한다. 탑다운 화면의 가독성을 유지하도록 강도를 조절한다.

## 숲 확장: 절벽과 야영 소품

- 숲에 어울리는 오브젝트를 추가 모델링하고 직접 배치한다.
- 돌벽 옆면의 언덕을 조립할 **키가 큰 절벽 메시 3종**을 만든다. 지면 아래로 묻는 깊이를 바꾸어 노출 높이를 조절하며, 하단이 계속 이어지는 구조로 제작한다.
- 절벽의 실루엣과 층리·돌출을 달리해 반복감을 줄인다. 재질은 **애니 배경풍 텍스처와 푸른 스카이 라이트가 반영된 암부 색**을 사용한다.
- **나무 이정표**, **천막**, **화톳불**, **캠핑 요리 도구**와 야영 생활을 보여주는 소품을 제작한다.
- 리드타임을 줄이기 위해 **모델링을 개별 병렬 에이전트 작업으로 분담**한다. 최종 배치와 언리얼 레벨 저장은 한 작업에서 순서대로 적용한다.
- 새로운 개별 레퍼런스와 텍스처 원본, Blender 스크립트·모델·배치 데이터를 보관하고 작업 단위마다 커밋한다.

## 현재 확인된 도구 제약

- 컴퓨터 사용 플러그인의 언리얼 창 캡처가 `SetIsBorderRequired (0x80004002)`로 실패했다.
- 플러그인의 제공 API에는 데스크톱 전체 캡처 전환이 없다. 언리얼 창 접근성은 제목만 반환했다.
- 사용자와 협의한 제작 흐름에 따라 블렌더 배치 데이터와 언리얼 에디터 스크립트를 사용한다.
- 생성 참고 이미지를 실제 언리얼 결과물로 표시하지 않는다. 실제 렌더 검증 결과를 별도로 저장한다.
