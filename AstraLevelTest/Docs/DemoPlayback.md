# 데모 영상 모드

게임 플레이 중 **P**를 누르면 7개 장소를 순서대로 촬영하는 자동 산책 모드에 들어간다. 각 컷의 시작 위치로 고양이와 카메라가 함께 순간이동하고, 짧게 장소를 보여준 뒤 고양이가 지정된 경로를 걷는다. 마지막 컷이 끝나면 첫 컷부터 반복한다. P를 누른 채 유지해도 반복해서 토글되지 않는다.

다시 **P**를 누르면 촬영을 시작했던 위치·방향·이동 속도·카메라 너비·추적 지연과 원래 시점으로 돌아와 WASD로 플레이할 수 있다. 데모 중에는 산책 경로가 고양이를 제어한다. 전환은 즉시 컷이며 지도 전체를 가로지르는 카메라 이동은 없다. P는 촬영용 연출을 재생하고, 영상 녹화는 사용 중인 캡처 도구에서 시작한다.

| 순서 | 장소 | 최소 컷 길이 | 구성 |
| --- | --- | --- | --- |
| 1 | 공터·피크닉 | 10초 | 풀과 나무 사이를 짧게 돌아 걷기 |
| 2 | 정상 나무다리 | 10초 | 개울 위 다리 중심선 횡단 |
| 3 | 분홍 집 | 11초 | 진입로에서 집 앞 생활 공간으로 산책 |
| 4 | 언덕 야영지 | 13초 | 경사로를 올라 천막과 화톳불 주변 소개 |
| 5 | 목조 폐허 | 9초 | 잔해 바깥을 지나 전면 소개 |
| 6 | 낚시 데크 | 10초 | 경사로와 데크를 걸어 낚시 자리에서 정지 |
| 7 | 무너진 다리 | 9초 | 수리 소품이 있는 접근로에서 정지 |

한 바퀴는 약 72초다. 각 컷은 시작 1초, 경로를 다 걸은 뒤 최소 1.5초를 정지하며 이동 시간이 길어지면 컷도 늘어난다. 카메라는 기존 Pitch −58° / Yaw 0°를 유지하고 장소별 직교 너비와 중심 위치만 바꾼다.

## 구현과 편집

`AAstraController`의 `DemoPlayback` 컴포넌트가 재생을 담당한다. `AstraDemoPlayback.cpp`의 기본 `Shots` 배열에서 순서, 월드 XY 경로(cm), 속도, 컷 길이, 카메라 너비와 오프셋을 변경할 수 있다. 컨트롤러 Blueprint에서는 같은 배열을 Details에서 편집할 수 있다. 이 기능은 코드로 구성되며 Level Sequence 자산은 만들지 않는다.

컷 시작 높이는 실제 충돌면을 추적해 구한다. 다리와 데크 위 걷기는 일반 CharacterMovement와 기존 보행 애니메이션을 사용한다. 길이 막히거나 지지면을 잃으면 해당 컷을 종료하고 다음 장소로 넘어가며, 시작 지점이 막힌 경우 플레이 상태를 복원한다. 저장된 레벨·배치·Foliage는 수정하지 않는다.

## 실행 검증

Editor 빌드 후 PowerShell에서 `Scripts/validate_demo_playback.ps1`을 실행한다. 별도 실제 게임 프로세스에서 P 입력 이벤트를 주입해 진입, 키 유지, 7개 컷 보행, 반복, 원래 상태 복원, 재진입·즉시 취소, 복귀 후 WASD를 검사한다. `ArtSource/Previews/UE_DemoValidation.json`과 컷별 `UE_Demo_*.png`를 저장한다. 이 검증은 별도의 `-AstraDemoTest` 실행 옵션을 지정했을 때만 작동한다.

2026-09-07 UE 5.7.4 실제 게임 검증에서 전체 항목이 통과했다. 7개 컷 모두 지지면을 잃은 시간이 0초이고, 복귀 위치·회전 오차는 0이다. [전체 검증 기록](../VALIDATION.md)과 [기계 판독 결과](../ArtSource/Previews/UE_DemoValidation.json)를 보관한다.
