## Puddle sky texture

Use case: illustration-story. Asset type: a sky reflection texture for small shallow forest puddles in an adorable low-poly top-down Unreal Engine game. Create one square 1024x1024 image showing ONLY a hand-painted Japanese animation background sky as if looking straight upward: tranquil powder-blue and light turquoise sky with several luminous ivory cumulus cloud masses, subtle pale lavender cloud undersides, loose elegant gouache brush texture, broad readable shapes, soft gentle warm afternoon atmosphere, painterly animation film background style.
